Raw .npz files for AlkaneCarbonyl, FluorideCarbonyl, and Benzene can be found in the original GraphXAI github repository.
https://github.com/mims-harvard/GraphXAI

Raw Mutagenicity files are automatically downloaded.
HouseColors raw files can be found in the original github repository https://github.com/AntonioLonga/Explaining-the-Explainers-in-Graph-Neural-Networks

Raw files for BA2grid, GridHouse, and BA2Motif, are provided as they introduce counterexamples that extend the scope of the original datasets.

The OpenGraphXAI datasets can be found the following repository alongside their splits:
https://github.com/OpenGraphXAI/benchmarks

To use the original splits, rename them to OGX[dataset_name]_HO_val0.2_test0.1__stratifyingTrue.pkl.
For the alfa splits the corresponging filename is OGXalfa_HO_val0.2_test0.1__stratifyingTrue.pkl.
